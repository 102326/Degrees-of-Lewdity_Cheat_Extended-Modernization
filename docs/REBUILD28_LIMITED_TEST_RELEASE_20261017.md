# Cheat Extended 1.20.3.1-rebuild.28：限定测试说明

这是保留原CE界面的重制限定测试版，适合愿意在独立副本或可回滚环境中试用、反馈问题的玩家。**暂不作为面向所有旧用户直接覆盖升级的正式稳定版。**

## 有什么变化

- 退出已停止维护的Simple Framework路径，继续使用原游戏与MapleBirch接口。
- 金钱改用游戏原生交易入口；整理Hook、时间事件、战斗边界及功能停用后的资源清理。
- 服装特质和自定义颜色按实际修改目标记录归属，保留原库存、穿戴及第三方状态来源。
- 整理敌方状态面板、侧栏、菜单、语言转换、外观刷新和五张探索地图的临时回调与节点。
- 修正排序窗口关闭接线和动态文字排除区域，保留既有菜单、面板与操作入口。

## 备份、安装与回滚

1. 先备份原CE包和升级前的原存档，保留能恢复的旧环境。
2. 在独立副本或可回滚环境中，通过原ModLoader或所用管理器的正常导入入口安装；同一环境保留一份CE。
3. 按依赖提示安装并重启游戏，确认版本为`1.20.3.1-rebuild.28`。有依赖或加载错误时先保留错误信息，避免继续覆盖原存档。
4. 需要回滚时，使用升级前的原CE包和原存档备份。**新版保存不保证旧版可读**，不要把新版另存文件当成降级备份。

固定上游`1.20.3.1`源码原生生成的代表性旧版样本，已由28完成读入、另存、跨文档再读及设置重置。该专项仅在Windows执行；作者发行ZIP、真实玩家长期旧档、Android升级等尚未验证，**不承诺任意旧用户可直接覆盖升级**。

## 已知边界

- 停用或重置不撤销已经发生的金钱、时间、库存、穿戴等游戏效果，也不等于恢复全部外观。
- 服装单件“套回初始特质”与批量“撤销全部覆写”作用不同；关闭自动预设后，已打开的手动面板仍可操作。
- 排序窗口按“唯一元素子节点”识别归属。第三方仅追加纯文本兄弟节点时，仍可能随窗口关闭；复用同一CE容器的内部接管也不能自动区分。
- 外观渲染管线在页面边界同步。第三方在同一页面稍后替换整个管线时，需要下一页面边界；静态Macro、CSS及部分框架接入保留，不承诺整包热卸载。
- Windows测试准备时曾记录一次原生天气背景异步回调异常，根因unknown；没有证明由CE引起，后续通过只覆盖已记录步骤。
- 其它设备、版本、Mod组合、损坏档、云端、全部玩法/视觉及性能矩阵未验证。开发方验证与独立文件复核按各自范围使用，不代表独立方重跑了全部测试。
