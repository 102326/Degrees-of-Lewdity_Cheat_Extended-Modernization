## 本轮功能结果

| 范围 | 已实现与证据边界 |
| --- | --- |
| R01 DeepProxy 注销 | 注销后既有根/子代理引用立即透传，不 revoke。登记更新后可重新安装；解开 CE 自己的旧代理再包新代理，避免叠加。对绑定的 State、注册根及父对象身份检查失活与重绑。夹具通过。 |
| R02 保存规则清算 | 三引擎按 owner 保留内置、保存、临时规则。Passage 时按当前保存列表差集清算，移除缺失、禁用或不再获准执行的保存规则；A→B→A、首次内置登记及禁用转存通过。未真实读写存档。 |
| R07 规则身份 | 同引擎同路径不组合执行：最近一次明确登记的自定义规则生效，隐藏的内置/其他自定义规则仍保留，注销当前项恢复前序项。自动重建不改变已有顺序。注销一行不再删除整条路径的其他 owner。跨引擎竞争尚未解决。 |
| R07 嵌套宏 | finally 恢复进入宏前的锁值；嵌套调用不提前释放外层锁。this、返回及异常路径通过。 |
| 可选 Framework 查询 | 复用 Paisley Park 6.0 CE 配方，在三个脚本的四处严格名称查询前检查真实名称集合。保留 Maple/Simple 原分支，避免缺少可选项时制造 Loader 假错误；16 组表达式对照通过。没有据此宣称完整 Simple 支持。 |
| R08 资源闭合 | 移除四个不存在且无 Patch 引用的 additionFile 条目，补 Widgets_6.txt；全部 30 条 Patch 声明保留。作者 ZIP 已包含 Widgets_6，不能把源码清单问题写成作者发布包漏资源。 |

临时规则继续按原有“同一 JS 文档会话”保留，不在换档时无条件删除。
保存与临时规则仍使用原数据列表和 ID，没有按 CE_ 前缀清理数据。
登记使用实际保存后的规范 ID；替换、临时转保存和删除保持一致归属。
失效或安装失败的 binding 会被移除；旧 State 释放依据源码引用链检查，未测量 GC。
关闭作弊功能不撤销此前作弊效果；Raw/Var 注销为行为透传，不宣称还原原始属性描述符。

主要改动：`CE_hookRegistry.js`、`CE_hookTool.js`、`CE_hookSimpleUI.js`、`CE_macroHookTool.js`；
四处查询位于 `CE_sideBarIcon.js`、`CE_tattoo.js`、`CE_TimeTravelPlus.js`；装配见 `boot.json` 与 `build/package.mjs`。

## 构建与验证

Node.js 要求 >=22.12；本次使用 macOS ARM64、Node 24.18.0、npm 11.16.0。
在工程根目录运行：

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run verify
```

`npm run build` 生成 `dist/cheat-extended-r1.mod.zip` 与 `dist/assembly.json`。
`npm test` 使用 Node 内置 test runner；仅 JSZip 是开发依赖，不在游戏里加载。
安装构建依赖需要网络；运行制品未新增网络依赖。

本次完成的关键检查：

- 修复版 `npm run verify`：**28/28 通过**（24 项 Hook/相邻行为、1 项覆盖 16 场景的可选框架检查、3 项装配检查）。
- 固定旧版定向对照：`CE_TEST_BASELINE=1 node --test --test-name-pattern '^DeepProxy|saved A|permission revocation|nested macro' tests/hooks.test.mjs`：8 项目标断言失败、1 项原有行为通过，退出码 1 为预期。不是游戏运行故障统计。
- 原清单的遗漏 Patch 与缺失文件分别被装配器拒绝。现有输入生成 **89 个 ZIP 成员、7 个外置 Patch 文件**；重新读取真实 ZIP，CRC、成员和输入字节对应通过。同输入两次生成字节一致。
- 全部声明 JS 及普通脚本合并结果通过经典脚本解析；4 个 early、21 个 Twee、3 个 CSS 与原顺序保留，普通脚本只在 Hook 工具前增加注册表。
- 原许可证字节、Spectrum 通知与 OpenCC 来源说明保留；本地改动说明见 [R1-NOTICE.md](../R1-NOTICE.md)。
- 只读代码审查发现并修正禁用转存、失效 binding 保留旧 State、自动清算改变顺序三个分支；修复回查通过。
- `git diff --check` 通过。

声明、打包已验证；**Patch 命中与游戏运行未验证**。具体 ZIP SHA-256 以 `dist/assembly.json` 为准。
本机只发现旧的 vanilla 0.5.11.9 宿主，低于 CE 声明下限，未将其当作有效验收组合。
当前参考完整功能环境是 MapleBirch 路径；实际游戏版本、本地化、Loader 与 Patch 插件组合尚未固定并加载。
未运行 Windows、Android、真实 SugarCube 存取档、53 项全功能或第三方 Mod 共存验收；没有性能收益结论。
